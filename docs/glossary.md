# API engineering glossary

- **API:** a defined interface through which software components interact.
- **Contract:** the agreed operations, inputs, outputs, errors, and behavioural guarantees.
- **Endpoint:** an addressable API operation, commonly described by method + path.
- **Resource:** a conceptual entity exposed by an API, such as a book or order.
- **Representation:** a format used to transfer resource state, commonly JSON.
- **Idempotent:** repeating the same request has the same intended effect as performing it once.
- **Safe method:** a method intended to read rather than change server state.
- **BOLA:** broken object-level authorization; a caller accesses an object they are not permitted to access.
- **OpenAPI:** a machine-readable description format for HTTP APIs.
- **Webhook:** an HTTP callback sent when an event occurs.
- **SLO:** a service-level objective, a measurable reliability target.
- **Backward compatibility:** a change does not break existing supported consumers.
